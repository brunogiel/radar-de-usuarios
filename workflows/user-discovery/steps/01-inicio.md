# 01, Inicio y Nivel de Madurez

## Objetivo

Crear la carpeta de trabajo, entender que trae el usuario y ubicar el nivel de madurez.

## Notas del método

- Primero entender si la persona esta arrancando, ya probo algo o ya conoce usuarios.
- No empezar con soluciones.
- El guia explica el proceso y pide involucramiento activo.

## Documentos a tocar

- `descubrimiento/documento-discovery.md`
- `descubrimiento/state.yaml`
- `descubrimiento/decision-log.md`
- `descubrimiento/assumptions.md` si se avanza con supuestos

## Preguntas guia

- Que queres entender o mejorar?
- En que nivel estas: 0 a 5?
- Que material ya tenes?
- Que queda fuera de este discovery?

## Usar el template

Completar en `documento-discovery.md`:

- Objetivo del proyecto.
- Nivel de madurez y evidencia.
- Contexto inicial.
- Alcance y fuera de alcance.

Si el usuario trae documentos, registrarlos en `base-conocimiento.md` como fuentes cargadas.

## Gate

Status recomendado:

- `capturing` si falta contexto.
- `drafted` si hay objetivo, nivel y alcance.
- `validated` si el usuario confirma.
- `advanced_with_assumptions` si se avanza sin cerrar alcance.

Accion sugerida por default: `Profundizar`.

## Checklist antes de avanzar

- Hay un objetivo entendible.
- Hay nivel 0-5 justificado.
- Queda claro que no estamos buscando soluciones todavia.
- Hay una primera lista de materiales o contexto faltante.
