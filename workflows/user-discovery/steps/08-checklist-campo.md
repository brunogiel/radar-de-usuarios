# 08, Checklist de Campo

## Objetivo

Preparar protocolo para antes, durante y despues de entrevistar.

## Input de Bruno incorporado

- Pedir consentimiento.
- Cuidar privacidad.
- Usar grabacion o AI notetaker si se puede.
- Nunca cortar lo que esta diciendo el entrevistado.
- Todo lo que dice el usuario es evidencia de su perspectiva; no se discute en la entrevista.

## Documentos a tocar

- `radar/checklist-campo.md`
- `radar/state.yaml`
- `radar/decision-log.md`

## Checklist de calidad

- Antes.
- Durante.
- Despues.
- Errores a evitar.
- Nomenclatura de archivos.
- Politica de consentimiento y privacidad.
- Plan de contexto, si aplica.
- Permisos para fotos, grabaciones y materiales.

## Guia de contexto

Si el problema ocurre en un lugar, proceso o herramienta concreta, completar `guia-contexto.md`.

Usar observacion, shadowing, expertos, inspiracion analoga o materiales de uso segun el caso.

## Gate

Accion sugerida:

- `Avanzar` si el equipo puede entrevistar sin improvisar.
- `Profundizar` si faltan herramientas o consentimiento.
- `Cuestionar` si hay riesgo etico.
