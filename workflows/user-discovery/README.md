# User Discovery Workflow

Workflow principal de Radar de Usuarios.

Reglas:

- Leer solo el step activo.
- Actualizar `radar/state.yaml`.
- Actualizar `radar/documento-discovery.md`.
- Actualizar el documento de etapa.
- Registrar supuestos en `radar/assumptions.md`.
- Registrar decisiones en `radar/decision-log.md`.
- Usar templates como instrucciones, no solo como archivos vacios.
- Si hay trabajo de campo contextual, actualizar `radar/guia-contexto.md`.
- Para cada entrevista, bajar material crudo en `radar/interviews/incoming/`, registrar en `radar/interviews/index.md` y copiar `radar/interviews/notes/_template-notas.md`.
- Antes de sintetizar, extraer evidencia a `radar/interviews/evidence-ledger.md`.

Cada gate termina con recomendacion: Avanzar, Profundizar, Cuestionar o Concilio.
