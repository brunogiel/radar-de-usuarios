# Guia de Contexto

La investigacion no vive solo en entrevistas. Este documento planifica observacion, inmersion, expertos, analogias y materiales para entender el ecosistema real del usuario.

## Objetivo

Pendiente.

## Metodos posibles

| Metodo | Para que sirve | Cuando usarlo | Riesgos |
|---|---|---|---|
| Observacion en contexto | Ver lo que la gente hace, no solo lo que dice | Cuando el comportamiento ocurre en un lugar claro | Requiere permiso y tiempo |
| Shadowing | Seguir un proceso real de punta a punta | Cuando hay journey operativo | Puede alterar comportamiento |
| Inmersion | Vivir o experimentar parte del problema | Cuando el equipo tiene distancia con el usuario | No generalizar experiencia propia |
| Expertos | Entender contexto, jerga, regulacion o historia | Cuando falta mapa del sector | Expertos no reemplazan usuarios |
| Inspiracion analoga | Mirar problemas similares en otros dominios | Cuando el equipo esta bloqueado | Analogias no son evidencia |
| Materiales de uso | Ver documentos, herramientas, capturas, objetos | Cuando hay proceso tangible | Cuidar privacidad |

## Observacion

Durante observaciones mirar:

- Workarounds y adaptaciones.
- Objetos, papeles, planillas, chats, herramientas.
- Cambios de comportamiento.
- Lenguaje corporal.
- Cosas que sorprenden o parecen irracionales.
- Lo que contradice supuestos.
