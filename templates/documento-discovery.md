# Documento de Discovery

Este es el documento vivo del proceso. Resume el estado, conecta los subdocumentos y evita que la conversacion sea la unica memoria del proyecto.

## Como usar este documento

- Mantenerlo como indice ejecutivo, no como deposito de todo.
- Linkear o resumir lo importante de cada subdocumento.
- Separar hechos de supuestos.
- Registrar gaps en vez de esconderlos.
- Al final de cada gate, actualizar estado y proxima accion.

## Acciones disponibles

- `Avanzar`: pasar al siguiente paso con suficiente base.
- `Profundizar`: pedir mas input o ordenar mejor antes de seguir.
- `Cuestionar`: revisar encuadre, supuestos o evidencia.
- `Concilio`: convocar 3-5 agentes para tensionar una decision.
