# Base de Conocimiento

Este documento ordena el material temprano sin sintetizar de mas. En esta etapa se preserva trazabilidad: no borrar, no fusionar ideas distintas y no convertir supuestos en insights.

## Como trabajar esta etapa

- Volcar primero el material crudo.
- Separar lo confirmado de lo inferido.
- Mantener contradicciones visibles.
- Usar las palabras del usuario cuando haya citas.
- Marcar toda inferencia como `Lectura del copiloto`.
