# Reference Map

Radar is built from two kinds of background material:

- Author-owned facilitation material about user discovery, design thinking and qualitative research.
- External human-centered design references used as methodology background.

The public repository contains generic method files. Private PDFs, client material, company examples and restricted source documents remain outside the public package.

## External References

These sources informed the method structure and quality criteria:

- IDEO Field Guide to Human-Centered Design.
- IDEO.org Design Kit.
- IDEO + Acumen workshop materials on human-centered design.
- Public design thinking toolkits and field guides.

## Method Areas

- Framing and Design Challenge.
- Design research planning.
- Qualitative interviews.
- Research ethics, privacy and consent.
- Contextual observation and analogous inspiration.
- Synthesis, themes, insights and HMW questions.

## Use Policy

Radar keeps the method portable and original. It uses references as background, writes new operational guidance and generalizes private examples before they become part of the public repository.
